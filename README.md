# Video Downloader

Download videos from YouTube, TikTok, Facebook directly to your device.

## Features
- 📹 Video download to user's device
- 🎵 Audio extraction (MP3)
- 📱 Works on mobile and desktop
- ☁️ No storage on server
- 🚀 Fast streaming download

## How it works
1. User pastes video URL
2. Server downloads video temporarily
3. Video streams directly to user's device
4. Server deletes temporary file immediately
5. Nothing stored on server!
